# ThinkBot AI 🤖

A WhatsApp-style AI chatbot with multiple personas powered by Google Gemini AI.

## 🔗 Live Demo
[View Live App](https://thinkbot-ai-theta.vercel.app/)

## ✨ Features
- WhatsApp-style chat bubble UI
- 4 AI Personas (General, Coder, Writer, Teacher)
- Chat history saved to database
- Copy message button
- Clear chat functionality
- Loading animation while AI thinks

## 🛠️ Tech Stack
- Next.js, TypeScript, Tailwind CSS
- Google Gemini AI API
- Supabase (PostgreSQL)
- Vercel
